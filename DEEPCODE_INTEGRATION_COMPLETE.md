### **2. Optimisation de Code Existant**
```bash
# Code à optimiser
const oldCode = "...";

# Analyse DeepCode
POST /api/deepcode/analyze
{
  "code": oldCode,
  "context": {
    "language": "javascript",
    "framework": "react",
    "purpose": "optimization"
  }
}

# Optimisation automatique
POST /api/deepcode/optimize
{
  "code": oldCode,
  "issues": ["performance", "security"],
  "context": {
    "language": "javascript",
    "optimizationGoals": ["performance", "security"]
  }
}
```

### **3. Génération de Documentation**
```bash
# Code à documenter

{
```
